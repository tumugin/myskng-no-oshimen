# 推しメン調査資料

`oshimen/oshimens.ts` に登録されている全推しメンの公開情報を、1人1ファイルで整理した資料です。

## 方針

- ファイル名は原則として `所属グループ-名前.md` とする。
- 公式サイト、公式SNS、本人・運営のnote、一次インタビューを優先する。
- 公式情報が少ない場合のみ、音楽配信プロフィールやアイドル情報データベースを補助的に使う。
- 年齢や本名など、本人が継続的に公開していない情報は記録しない。
- 所属、メンバーカラー、SNS、活動状況は変わり得るため、各ファイルに調査日を記載する。
- 推測と確認済みの事実を混ぜず、確認できない項目は「未確認」とする。

## 各ファイルの読み方

- 「基本情報」は名前、所属、誕生日、担当色、公式SNSなどを素早く確認する欄。
- 「活動・人物メモ」「公開プロフィール」は公式プロフィールを読みやすく要約した欄。
- 「詳細メモ」は加入時期、活動歴、趣味・特技、作品、個人タグ、表記上の注意など、紹介文を作る際に使える細目。
- 「このリポジトリで注目している要素」は公開情報と作者固有の思い出・呼称を切り分ける欄。
- 「更新時の注意」は所属変更やファン内のネタなど、将来誤読しやすい点を記録する欄。
- 「出典」はその人物を再調査するときの起点。本人・運営の一次資料を先に並べる。

## 情報の確度

1. 本人・運営の公式サイト、公式SNS、公式noteを最優先する。
2. 本人が発言した一次インタビュー、レーベルや音楽配信サービスのプロフィールで補完する。
3. ファン編集型データベースは、過去所属や日付を探す補助資料としてのみ使い、可能な限り一次資料と照合する。
4. リポジトリ独自の呼称や思い出は、一般的なプロフィールと明確に分ける。
5. 年齢、身長、血液型など現行公式ページにない情報は、出典と公開時点を確認できない限り断定しない。
